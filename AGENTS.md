# Agent Instructions

This repository keeps reusable workflows under `.agents/skills/`.

Before changing a workflow, read the relevant skill file:

- Installation or dependency setup: `.agents/skills/x2real-install/SKILL.md`
- X2Real ID evaluation: `.agents/skills/x2real-id-eval/SKILL.md`
- X2Real manual gendata (keyboard, VR, master arms): `.agents/skills/x2real-gendata/SKILL.md`
- Policy Space service integration: `.agents/skills/policy-service/SKILL.md`

Treat the skill instructions as repository-specific guidance. Keep changes scoped
and run the validation requested by the relevant skill before reporting completion.
